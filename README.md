### 🚀 Featured Engineering Projects

#### 🩺 [Med Assist AI](https://github.com/JAIII12/med_ui)
> **AI-Powered Healthcare Guidance & Medical Assistant Platform**
- **Overview:** Interactive intelligent medical assistant offering symptom triage, drug interaction verification, mental health support, and health vitals tracking.
- **Key Highlights:** Real-time conversational AI integration via Google Gemini API, secure user session persistence with Supabase, responsive medical dashboard with interactive self-assessment tools.
- **Tech Stack:** `React 18` • `TypeScript` • `Tailwind CSS` • `Vite` • `Supabase` • `Google Gemini API`

#### 🌿 [Product Eco-Friendliness Index (PEFI)](https://github.com/JAIII12/my-prediction-comp)
> **Machine Learning Lifecycle Sustainability Scoring & Classification System**
- **Overview:** End-to-end data science pipeline and interactive Streamlit web dashboard benchmarking consumer product sustainability across lifecycle attributes.
- **Key Highlights:** Multi-model regression benchmarking (Random Forest, XGBoost, MLP Regressor), discrete eco-impact tier classification, dynamic Plotly radar/gauge analytics, and batch CSV predictions.
- **Tech Stack:** `Python` • `Streamlit` • `Scikit-Learn` • `XGBoost` • `Pandas` • `Plotly` • `Seaborn`

#### 🚨 [Campus Crisis Radar](https://github.com/JAIII12/campus-crisis-radar)
> **Real-Time Campus Safety Incident Reporting & Emergency Management Platform**
- **Overview:** Full-stack crisis response platform enabling students to report emergencies, broadcast one-click panic alerts, and track incident status on real-time campus heatmaps.
- **Key Highlights:** WebSocket-based live dispatch updates, geo-tagged alert routing, role-based admin dashboard with incident resolution lifecycles.
- **Tech Stack:** `React` • `Node.js` • `Express.js` • `MongoDB` • `Socket.io` • `Leaflet.js`

#### ⚖️ [LexVault Law Firm System](https://github.com/JAIII12/lexvault-law-firm-system)
> **Enterprise Legal Case Management & Workflow Automation System**
- **Overview:** Secure, production-grade law firm operational platform streamlining client intake, court deadline tracking, document versioning, and billing records.
- **Key Highlights:** Strict Role-Based Access Control (RBAC) across partners, associates, and clients; relational schema modeling; tamper-evident audit logging and automated PDF invoicing.
- **Tech Stack:** `React` • `Node.js` • `PostgreSQL` • `Prisma ORM` • `Docker` • `Tailwind CSS`

#### 🎬 [MovieHub](https://github.com/JAIII12/movie_hub)
> **Modern Movie Discovery & Personal Watchlist Application**
- **Overview:** Sleek, high-performance web application integrating with The Movie Database (TMDB) API for real-time title searches and trending movie feeds.
- **Key Highlights:** Client-side routing with React Router v7, global state management via React Context API, local storage synchronization for bookmarked favorites, and responsive dark mode grid UI.
- **Tech Stack:** `React 19` • `Vite 6` • `React Router v7` • `CSS Grid/Flexbox` • `TMDB REST API`
